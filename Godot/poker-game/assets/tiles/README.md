# 疊牌消消 tile pictures

Put images here (PNG, JPG, WebP or SVG) and each one becomes an extra tile kind
in 疊牌消消, right after the four card suits. They are used in file-name order,
so name them `01_xxx.png`, `02_xxx.png`, ... to control which appear first
(early levels only use the first few kinds).

- Square-ish images with a transparent background look best; they are scaled
  to fit the tile face (about 40 × 52 pixels).
- Only use images you have the right to use. See CREDITS.md for where the
  current pictures come from.
